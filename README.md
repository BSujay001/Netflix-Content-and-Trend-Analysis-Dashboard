# 🎬 Netflix Trend Analysis - Power BI Dashboard

An interactive Power BI dashboard analyzing Netflix's movie and TV show catalog to uncover content production trends, geographical distribution, and genre preferences.

---

## 📌 Project Overview
This project explores the evolution of Netflix's content library. Using Power BI, I built an executive-ready, dark-themed dashboard that allows users to slice and dice data by release year, country, rating, and genre.
